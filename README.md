# Домашнее задание: Основы вёрстки и Бэкенд на чистом Python

Проект представляет собой локальный веб-сервер на чистом Python с адаптивной вёрсткой страниц на Bootstrap 5.

## 🎯 Цели и задачи
* Изучить основы HTML-разметки и стилизации веб-страниц [jork58, AwLCHz].
* Интегрировать фреймворк **Bootstrap 5** для создания адаптивного интерфейса (Sidebar + основной контент) [jork58, WhvsFC].
* Написать собственный HTTP-сервер на чистом Python с использованием встроенного модуля `http.server` [jork58].

## 🛠️ Выполненные требования
1. **Адаптивная вёрстка**: Созданы три страницы сайта (`index.html` — Главная [4vJkUg], `catalog.html` — Каталог [y9XVgB], `contacts.html` — Контакты [AwLCHz]). Стилевой файл Bootstrap подключен автономно (`/css/bootstrap.min.css`).
2. **Веб-сервер**: Настроен сервер на Python, возвращающий корректные заголовки `Content-Type: text/html` и `text/css`.
3. **Контекстные менеджеры**: Чтение всех файлов выполняется строго с помощью конструкции `with open()` [jork58].
4. **Обработка POST-запросов**: Реализован приём данных из формы контактов и вывод в консоль.
5. **Дополнительный функционал**: Настроена обработка ошибок `404 Not Found`.

## 🚀 Инструкция по запуску
Запустите сервер в терминале:
`python server.py`
Откройте в браузере адрес: http://127.0.0.1:8000
